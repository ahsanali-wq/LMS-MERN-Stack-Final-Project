# LMS-MERN-Stack-Final-Project
#Project Overview
This is a complete Learning Management System (LMS) developed using the MERN Stack. It supports Admin, Instructor, and Student roles with protected routes and role-based access.
#Frontend: React JS, React Router, Axios, Bootstrap
#Backend: Node.js, Express.js
#Database: MongoDB & Mongoose
#Security: JWT Authentication & Bcrypt Password Hashing
The project follows a proper MVC (Model-View-Controller) architecture with separate folders for models, controllers, and routes to ensure industry standards.
